# Audioguia Cultural SJC

MVP de uma plataforma web para exposições culturais, com acesso por QR Code, conteúdos em texto, áudio, audiodescrição, Libras e métricas de acesso por obra.

## Objetivo

Desenvolver uma solução tecnológica que facilite o acesso do público aos conteúdos de exposições culturais, proporcionando uma experiência rápida, intuitiva e acessível.

O projeto será desenvolvido como atividade extensionista junto à comunidade, tendo como instituição parceira a Casa de Cultura Chico Triste, em São José dos Campos - SP.

## MVP

A primeira versão será demonstrada utilizando uma exposição fictícia composta por três obras.

Cada obra terá um QR Code próprio para acesso ao seu conteúdo.

O MVP contemplará:

- Cadastro de exposições;
- Cadastro de obras;
- Conteúdo textual;
- Áudio;
- Audiodescrição;
- Vídeo com conteúdo em Libras;
- Geração de QR Codes;
- Acesso público por QR Code;
- Métricas de acesso por obra.
